## 🚀 Features

This repository contains real-world examples across multiple AWS services:

### *S3*
- Event notifications (SNS/SQS integration)  
- Glacier storage & lifecycle management  
- Static website hosting  
- Multipart uploads  
- Object locks & versioning  
- Replication & object tagging  
- SDK examples (Java, Ruby)  
- Powershell & Terraform/CDK IaC examples  

### *VPC*
- Create & delete VPCs  
- Internet & NAT gateway setups  
- Security groups & NACLs  
- Gateway & interface endpoints  
- VPC peering examples  

### *Compute & Messaging*
- Lambda & Step Functions workflows  
- SNS/SQS standard & FIFO queues  
- Server logs handling  

### *Machine Learning*
- SageMaker metrics and notebooks  

### *Other Services*
- Secrets Manager (basic examples, DB masking)  
- Textract document analysis  
- Translate text translation  
- Static website hosting templates  

### *Infrastructure as Code (IaC)*
- Terraform configurations  
- AWS CDK projects  
- CloudFormation templates
